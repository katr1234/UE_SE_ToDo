# Beschreibung ToDoApp

Die ToDo-App soll Aufgaben innerhalb einer Organisation verwalten. Die Anwendung soll innerhalb einer Organisation eingesetzt werden und die Mitarbeitenden bei der Verwaltung, Planung und Verteilung von Aufgaben unterstützen.  
Durch die Erfassung von Arbeitszeiten pro Aufgabe und die Darstellung des Fertigstellungsgrades soll der Aufgaben- und Projektfortschritt übersichtlich und transparent dargestellt werden. Aufgaben können zusätzlich in Subaufgaben unterteilt werden.  
Für eine bessere Organisation sollen außerdem mehrere Aufgaben und Subaufgaben zu Arbeitspaketen zusammengefasst werden können. Diese ermöglichen ebenfalls eine Übersicht über den aktuellen Arbeitsfortschritt.
